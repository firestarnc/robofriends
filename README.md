# 🤖 RoboFriends

RoboFriends is a **React-based web app** that displays a list of robot profiles and allows users to **search/filter** them in real time. It’s a beginner‑friendly project often built as part of learning React and Redux. :contentReference[oaicite:1]{index=1}

📍 **Live demo (GitHub Pages):**  
https://firestarnc.github.io/robofriends/

---

## 🧠 What It Does

- Displays a grid/list of robot profiles (name + placeholder robot image).
- Lets users type in the search box to filter robots by name.
- Built using **React** (and optionally **Redux**, depending on implementation). :contentReference[oaicite:2]{index=2}

---

## 🛠️ How It Works

This project was likely bootstrapped with **Create React App**, which sets up a modern JavaScript build environment with zero configuration. :contentReference[oaicite:3]{index=3}

Key features:

- **React components** to render UI
- **State and props** for dynamic filtering
- Optional **Redux** for state management
- **Fetch** or placeholder data for robot information

## 🚀 Getting Started (Development)

If you want to work on this locally, follow these steps:

1. **Clone this repository:**
   ```bash
   git clone https://github.com/Firestarnc/firestarnc.github.io.git
2. Go into the RoboFriends directory:
   ```bash
   cd firestarnc.github.io/robofriends
3. Install dependencies:
   ```bash
   npm install
4. Start the development server:
   ```bash
   npm start
5. Open in your browser:
   http://localhost:3000
  The app will reload automatically as you edit the code. Huy23tran11
